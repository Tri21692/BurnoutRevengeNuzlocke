# Legacy Python tracker

The first version of the tracker, written in Python with a Tkinter window. It has been replaced by
[`bin/nuzlocke.exe`](../bin/nuzlocke.exe) (source in [`tracker/`](../tracker)), which needs no Python and
supports everything added since: crash junction blocking, the finished-event signal, the AI level and
patched ISOs. Kept for reference only.
